# Plany

## Kolejny etap: listy od uczestników

Na stronie z wynikiem losowania pokazujemy list, który wysłała obdarowywana osoba lub para.
Listy mają mieć ładną grafikę i czcionkę.

### Pomysł na realizację (do potwierdzenia)

- **Pliki:** `<dom>/<rok>/listy/<uczestnik>.txt` (albo `.md`): treść listu od danej osoby lub pary.
- **Wyświetlanie:** po otwarciu prezentu, pod wynikiem, przycisk „Przeczytaj list od …”.
  Otwiera kartkę z listem.
- **Grafika:** stylizacja papieru listowego, np. kremowe tło z delikatną fakturą, ozdobny nagłówek
  (gałązka jodły / znaczek pocztowy / pieczęć lakowa), rozwijanie albo wyjmowanie listu z koperty.
- **Czcionka:** odręczna z polskimi znakami, z Google Fonts. Kandydaci do sprawdzenia:
  „Caveat”, „Kalam”, „Marck Script”, „Great Vibes” (nagłówek). Przed wyborem trzeba sprawdzić,
  czy dana czcionka ma ą, ę, ł, ś, ż, ź itd.
- **Bęczarka:** jest list od pary. Do ustalenia, czy jest też osobny list od dziecka.

### Pytania otwarte

1. Jak listy trafiają do repo: ktoś je przepisuje i dodaje jako pliki, czy potrzebny jest
   formularz na stronie? Formularz wymaga zapisu po stronie serwera, a GitHub Pages
   to tylko statyczne pliki.
2. Kto widzi list: tylko osoba, która wylosowała autora, czy wszyscy?
3. Czy listy mają być tekstem, czy mogą to być zdjęcia lub skany odręcznych listów?
4. Czy listy dzieci (Bęczarka) są osobno, czy w liście pary?
5. Prywatność: strona GitHub Pages jest publiczna, więc każdy, kto zna adres pliku, może przeczytać list.
   (To samo dotyczy dziś wyników losowania.)
