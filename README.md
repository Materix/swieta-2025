# swieta-2025

Świąteczne losowanie prezentów. Wyniki: `<rok>/<osoba>.txt` (plik = kto daje, treść = komu).

Strona z wynikami (GitHub Pages): `https://materix.github.io/swieta-2025/?osoba=<Imię>`
Domyślnie pokazuje bieżący rok; inny rok wybierzesz z listy na stronie (albo `&rok=2025` w adresie).
Po kolejnym losowaniu dopisz nowy rok do listy `YEARS` w `index.html`.
